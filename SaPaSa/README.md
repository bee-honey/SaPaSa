# SaPaSa

SaPaSa is a SwiftUI iOS app for Carnatic song practice. This v1 implementation includes bundled sample songs, search, filters, favorites, expandable song metadata, Notes/Lyrics practice tabs, a conditional Video tab, and a bottom audio-player shell for Notes and Lyrics.

## v1 Scope

- Home song list
- Search by song, raagam, thalam, or artist
- Filter by raagam, thalam, audio, and video availability
- Favorites tab with empty state
- Song detail screen
- Expandable artist, thalam, and raaga lakshanam details
- Notes and Lyrics tabs
- Conditional Video tab
- Mocked mini audio player
- Settings refresh placeholder for future GitHub sync
